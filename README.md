# Rockstone Quarry Management ERP (MERN Frontend Mockup)

This is the complete React + Tailwind CSS frontend project for the Quarry Management System.

## Features Included:
1. **Main Dashboard**: Tracks Total Quarry Sales, Purchases/Expenses, Net Quarry Profit Balance, and Remaining Government Transit Passes.
2. **Sales Module (Agent & Sub-Buyer Hierarchy)**: Click on an agent like **Naveen** to expand sub-buyers (**Sam, Raj, Kumar**) and filter or add loads (`20mm Jalli`, `M-Sand`, `P-Sand`, `Rough Stone`).
3. **Purchase & Rent Module**: Track operational quarry costs like **JCB Rent**, **Food Rent (Mess & Tea)**, **Hitachi Rent**, **Tipper Diesel**, and **Blasting**.
4. **Government Pass Tracker**: Record bulk transit pass batches bought from the Dept of Geology & Mining and automatically deduct passes used in lorry sales.

## How to Run Locally:
1. Extract this ZIP file.
2. Open a terminal in the project folder and install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
